# Preflare_indicators
Master Thesis Project Code

This contains code used in my Master Thesis at the University of Bern, for the thesis "Analyzing Preflare Activity with Clustering Techniques: A Machine Learning Perspective". Parts of the code originate from @jonaszubindu and @Brandonleighpanos. Please check their github repositories for further information and context of their usage of that code. Methods and code from both are marked as such in the different code files uploaded.

# Files:
Flare_cleaning_and_video.ipynb
Contains code for cleaning observations and creating videos.

Kmeans_Main.ipynb

All analysis methods used in the master thesis.


som.py
Code from Brandon Panos to create a self-organizing map (SOM) to solve the traveling salesman problem.

utils_data_prep.py
utils_features.py
Code mostly unmodified from Jonas Zbinden.

utils_kmeans.py
First half further kmeans and auxiliary methods, second half from Brandon Panos.
